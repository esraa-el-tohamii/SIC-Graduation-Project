UNDER THE HOOD

Built to see the pattern.

A two-stage pipeline turns daily consumption into a model risk score.

01

Prepare

1,034 chronological daily readings. Missing values are filled, outliers capped, and the CNN input scaled per consumer.

02

Recognize

Five WideDeepV2 CNNs analyze daily and weekly patterns. Their scores are averaged into one ensemble feature.

03

Assess

XGBoost combines raw readings, missing-data fraction, and the CNN score. A 0.5 threshold determines the review flag.

Interpreting the result

A model score is not calibrated proof of theft. Flagged consumers require human review. The supplied CNN ensemble differs from the cross-validation CNNs used to train the stack; exact evaluation equivalence has not been established. See the project README for provenance details.
